# Review Cycle

Review the actual diff against origin/main. Check saved metric indices, all locales, round and rectangular shapes, response status/type validation, native bundling, timeout and hide/resume behavior, late replies, settings persistence and rider changes. Fix valid findings in separate Conventional Commits when authorized. Re-run affected checks. Do not invent findings or claim hardware proof from tests.
